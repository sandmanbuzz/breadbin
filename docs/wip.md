## Rules of the road

- Local `main` in the primary clone is the shared truth. Origin is a mirror; a push waits for the owner's go (`docs/process.md`, "Origin"; decided: push at the first numbered release).
- Each session works in its own worktree. Land on local `main` under the land lock (`tools/with-lock -r land -- ...`), and say what was run and not run in the commit message.
- A commit records state, not success: red is fine when it is what you are working on.
- Emulator runs go through `tools/ci/run.sh`; timing runs take every slot with `BREADBIN_CI_EXCLUSIVE=1`. Since 2026-11-23 the vice pool is 12 slots and a work unit takes at most six (`docs/process.md`). Hardware runs take `tools/with-lock -r ultimate -- ...`, announce the write first, restore the configuration by trap, and read it back.
- Owner decisions still in force from the 2026-11-06 retro: the size ledger gets one row per landing; `make` is the `test-host` backstop (`test-host` builds first); NBUF is a build-constant experiment, a perf study a nice-to-have; footprint Level 1 approved, Level 2 on the table, Level 3 deferred to a corner.
